# Home and quote entry critique

Mode: Critique Mode  
Scope: planned home hero, customer paths, offers, and gallery entry  
Primary task: choose the appropriate quote path and provide enough information for evaluation  
Primary visual anchor: packaging form and real work, not a generic factory photograph

## Blocking findings

- `EMPHASIZE` — Make the two customer paths the first decision below the Thai-first value proposition. Acceptance: both paths are visible without scrolling on representative desktop and reachable within the first mobile viewport after the hero copy.
- `REPLACE` — Replace “instant quote” or price-like language with an evaluation CTA. Acceptance: no UI promises an automated price or response time.
- `REMOVE` — Omit trust metrics, client logos, factory claims, lead times, and contact facts until approved evidence exists. Acceptance: initial HTML contains no unverified factual claim or placeholder brand.
- `MERGE` — Present Starter, Growth, and Scale as one stage-based comparison rather than three equal floating cards. Acceptance: the visitor can distinguish audience and next action by reading one continuous section.
- `EMPHASIZE` — Render published gallery content server-side as the main proof surface. Acceptance: gallery heading, items, image alt text, and links exist in raw HTML without client JavaScript.

## Refinements

- `REDUCE` — Keep navigation destinations to the implemented public routes; avoid utility links and repeated quote buttons.
- `MOVE` — Put detailed form fields on `/quote`; keep home focused on path selection and confidence-building context.
- `KEEP` — Use a persistent high-emphasis quote action in the header and a compact mobile action bar, provided it never obscures form controls.

Gate result: PASS for planning after the blocking findings are adopted.
